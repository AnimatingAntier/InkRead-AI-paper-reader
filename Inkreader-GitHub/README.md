# 砚读 InkRead

一个面向论文精读的 Windows 独立桌面应用。界面沿用“数字学者书房”的暖纸墨韵设计，支持 PDF 与 Markdown，并内置可追溯的多 Agent 阅读助手。

> 项目不包含任何 API Key、用户论文、阅读记录或下载后的本地模型。首次运行后产生的数据默认只保存在本机。

## 安装与运行

环境要求：Windows 10/11、Python 3.11+、Node.js 20+。

```powershell
git clone <your-repository-url>
cd InkRead
python -m pip install -r requirements.txt
npm ci
npm run build
python app.py
```

开发前端时，可先运行 `python server.py`，再在另一个终端运行 `npm run dev`。Vite 会将 `/api` 请求转发到本机服务。

打包后的便携版需要保留 `InkRead.exe` 与同目录的 `_internal` 文件夹，不要单独移动 EXE。文库、阅读进度和设置默认保存在：

```text
%LOCALAPPDATA%\InkRead
```

构建过前端后，也可以双击 `Start-InkRead.bat` 启动源码版本。

## 隐私与密钥安全

- 请在应用设置页填写自己的 AI、SerpApi 和百度翻译凭据；项目没有内置密钥。
- 也可以参考 `.env.example` 使用环境变量，但不要把填写过的 `.env` 提交到仓库。
- 本地设置、用户论文、标注、截图缓存、下载模型、日志和打包产物均已通过 `.gitignore` 排除。
- AI 问题及相关论文片段会发送给你选择的 AI 服务；启用百度翻译时，当前英文选区会发送给百度。
- 发布或提交代码前请运行 `python scripts/check_secrets.py .`。更完整的说明见 [SECURITY.md](SECURITY.md)。

## 已实现功能

- Windows 原生独立窗口，无需打开浏览器
- PDF 导入、结构化文本提取、页面渲染、缩放、翻页、文本选择与阅读进度
- Markdown 精排：标题层级、表格、引用、任务列表、代码块、图片、行内/块级 LaTeX 公式
- 本机私有文库、搜索、删除、阅读进度和多篇论文对比选择
- 文库与论文大纲共用左侧栏，可通过竖向导航按钮即时切换
- 大纲纵向阅读轨道、当前章节圆点和章节高亮随阅读进度同步
- PDF 双栏页面按栏选择文字，避免选区混入相邻栏内容
- PDF 顶栏内置荧光笔与自由画笔：多色标注、连续笔宽、独立橡皮擦和统一撤回
- PDF 批注按钮与荧光笔、画笔归入同一标注工具组，三种工具互斥切换
- Markdown 批注入口也位于阅读区下层工具栏，不占用应用主顶栏
- PDF 支持 `←` / `→` 快速翻页，按住空格并用鼠标左键拖动可平移大尺寸画布
- 高亮按文字位置保存，涂鸦按页面比例坐标保存；缩放、翻页或重新打开论文后仍能准确复现
- 标注按论文自动保存在本机，不会修改原始 PDF 文件
- PDF 与 Markdown 通用论文批注：扫描原文后在页边生成关联批注卡，可直接编辑或交给 AI 撰写
- PDF 双栏批注会按原文所在的页面左、右半区自动分流，左右批注分别避让，减少长连线和单侧拥挤
- 批注卡闲置时自动收纳为页边小图标，鼠标移到对应图标后展开，移开即收回，避免大量批注持续撑长页面
- 批注原文与卡片双向联动，鼠标移入时自动强调；闲置透明度可在设置中连续调节
- 英文选区自动翻译：启动时检测百度翻译，正常时优先百度；额度耗尽或服务不可用时自动切换本地 OPUS-MT 英译中
- 同一选区译文采用会话级缓存；切换侧栏后再次查看不会重复消耗百度翻译额度
- 论文阅读区框选截图，可预览后随问题发送给 AI；支持 PDF、Markdown、公式、图表和现有标注
- 多模态模型直接接收截图；文本模型自动调用 Windows 本机 OCR，并以论文文字层作为离线兜底
- AI 设置内置 60 个 OpenCode Zen 模型下拉列表，按模型家族分组并同时显示名称与模型 ID
- PDF 与 Markdown 通用遮挡卡：可拖动、八方向缩放，并能在不透明复习和透明查看模式间即时切换
- 文档独立命名空间检索，避免多篇论文上下文串库
- 调度中枢、长上下文、网络检索、事实校验四类 Agent 的可视化协作轨迹
- 论文原文 `[P#]` 与网络来源 `[W#]` 强制隔离
- Semantic Scholar、Crossref 与 Google Scholar / SerpApi 学术检索
- OpenRouter、OpenAI 兼容 Chat Completions、OpenCode Zen Responses 接口
- AI 流式输出、来源抽屉、引用覆盖检查和低置信度提示
- AI 生成期间发送按钮自动切换为暂停按钮，可立即中断请求并保留已经生成的回答、来源和 Agent 轨迹
- 自动识别“最近、近期、SOTA、优于”等需要联网的问题
- 自动识别论文中缺少解释的术语问题，并尝试补充网络资料
- 论文和网络资料不足时，允许 AI 使用既有知识继续回答，同时明确标记为“需复核”
- OpenCode Zen 返回空正文时自动读取最终事件或使用精简上下文重试
- 夜读、沉浸模式、响应式多栏布局
- 夜读模式为阅读进度区提供高对比文字与环形进度配色
- 进入和退出沉浸模式时，左右栏淡入淡出并平滑收拢或展开

## AI 回答策略

回答内容分为三类：

1. **论文原文**：使用 `[P1]`、`[P2]` 等编号标注。
2. **网络检索**：使用 `[W1]`、`[W2]` 等编号并提供链接。
3. **AI 既有知识**：仅在现有资料不足时使用，单列“基于 AI 既有知识”小节，不伪造论文或网络引用。

当论文和网络检索均无法解释问题时，AI 不会只回复“未找到依据”，而会：

- 先说明当前资料不足；
- 再根据模型既有知识给出解释；
- 标注信息可能过时或未经当前来源核实；
- 在事实校验区显示“需复核”，避免误报为“已核验”。

例如询问 `Text-to-Mas是什么`，若论文和网络资料中没有定义，AI 会说明它可能是 `Text-to-Mask` 的截断或拼写遗漏，再解释文本到掩码任务，同时提示该判断需要复核。

## 多篇论文对比

1. 打开一篇论文作为当前主论文。
2. 在左侧文库中，将鼠标移到其他论文卡片上。
3. 点击卡片右侧的复选框按钮“加入多篇对比”。
4. 向 AI 询问核心创新、方法差异、实验指标、局限或后续改进。

AI 会在每篇论文的独立命名空间中检索，减少不同论文内容串库，并优先用表格展示比较结果。文库顶部会显示“已选 N 篇对比”。

## AI 设置

打开左侧齿轮，在“AI 与检索设置”中填写：

- 服务提供商
- Base URL
- 模型（从 60 个分组下拉选项中选择；旧版自定义模型仍会保留）
- AI API Key
- SerpApi API Key（可选，用于 Google Scholar 检索）
- 百度翻译 APP ID 与 API Key（可选；不填写时直接使用本地英译中）

未填写 AI Key 时，检索 Agent 与本地事实校验仍可运行，并展示命中的原文片段；填写后会生成完整综合回答。

当前已支持的接口形式：

- OpenCode Zen Responses API
- OpenRouter
- OpenAI 兼容 Chat Completions API

设置和密钥只保存在本机 `%LOCALAPPDATA%\InkRead\settings.json`。调用 AI 时，问题和相关论文片段会发送给所配置的 AI 服务。

百度大模型文本翻译需要同一百度翻译开放平台账号下的 `APP ID` 和 `API Key`。InkRead 每次启动会用一个极短文本检测百度是否可用；百度可用时优先调用，检测到额度耗尽或服务不可用时自动切换本地翻译。本地模型首次启用时下载约 160 MB 至 `%LOCALAPPDATA%\InkRead\models`，以后可离线使用且没有按字数计费。使用百度时只有当前英文选区会被发送；使用本地模型时选区不会离开设备。

## PDF 标注工具

- PDF 工具栏从左到右排列荧光笔、画笔和批注；切换工具时会自动退出上一种工具。
- 点击顶栏荧光笔后，选择文字即可高亮；再次点击可退出。
- 荧光笔工具展开后可切换五种颜色；开启橡皮擦后按住并划过文字，可逐词精细擦除高亮。
- 点击画笔后可直接在 PDF 页面上涂鸦，并可选择五种颜色；笔宽滑杆支持 `1–20px` 连续调节。
- 画笔橡皮擦采用真实擦除笔迹；工具栏撤回按钮和 `Ctrl+Z` 可撤回最近一次高亮、绘制或擦除。
- 所有标注都会自动保存到 `%LOCALAPPDATA%\InkRead\documents\<论文ID>\annotations.json`。

## PDF 阅读快捷键

- `←`：前一页。
- `→`：后一页。
- 按住 `Space`，再按住鼠标左键拖动：横向或纵向平移 PDF 画布。

当光标位于页码、批注编辑框、AI 输入框或设置输入框时，方向键和空格保持原有编辑作用，不会触发翻页或拖动画布。

## 截图提问

1. 打开 PDF 或 Markdown 论文，点击阅读区右上角的“截图”。
2. 在论文页面上拖拽框选需要分析的文字、公式、图表或插图；按 `Esc` 可取消。
3. 截图会立即作为附件出现在 AI 输入区，可以输入具体问题，也可以直接点击发送让 AI 解读。
4. 若当前模型支持视觉输入，InkRead 会通过 Responses API 的 `input_image` 或 Chat Completions 的 `image_url` 直接传图。
5. 若当前模型是文本模型，InkRead 会先调用 Windows 本机 OCR；若 OCR 不可用，则使用 PDF/Markdown 文字层的本机提取结果，不会把图片发送给文本模型。

截图只保存在当前聊天会话内，不写入文库或原始论文。使用视觉模型时，框选图片会发送给所配置的 AI 服务；使用文本模型时，仅 OCR 文字会随问题发送。

## 论文批注

1. 打开 PDF 或 Markdown，点击阅读区顶部的“批注”按钮。
2. 像普通复制文字一样拖动扫描原文；松开鼠标后，原文会被浅金色标记，右侧自动出现与其相连的批注卡。
3. 点击卡片正文即可直接编辑。点击卡片底部的“AI”按钮，可让当前设置的 AI 根据所选原文生成简洁中文注释。
4. 鼠标移到原文标记或批注卡上时，两者会同步变得清晰；鼠标移开后卡片恢复半透明，减少对论文正文的遮挡。
5. 在“设置 → 论文批注卡”中拖动“闲置透明度”，可即时调整所有批注卡的淡化程度。
6. 批注会自动保存到 `%LOCALAPPDATA%\InkRead\documents\<论文ID>\annotations.json`，重新打开论文仍会恢复；点击卡片右下角的删除按钮可移除批注。

AI 生成批注时只发送当前选中的原文和论文标题，不会发送整篇论文。手写内容与 AI 内容都可以继续修改。

PDF 批注卡会按照标注文字位于页面左半还是右半，自动放到最近的页边。左右两侧分别计算避让位置；编辑或 AI 生成使卡片高度变化后，后续卡片与折线连接会即时重新排布。批注较多、两侧空间同时启用时，阅读区支持横向和纵向滚动，不会裁掉超出单页高度的批注。

鼠标不在批注卡上时，每条批注只显示一个带编号的小图标，并按紧凑高度排列。将鼠标移到某个图标上会自动展开对应的完整批注卡；移开后立即收纳，其他批注也会恢复紧凑位置。正在编辑卡片正文或操作 AI 按钮时，卡片会保持展开。

## 遮挡卡

1. 打开 PDF 或 Markdown，点击阅读区顶部的“遮挡”按钮。
2. 拖动卡片可移动位置，拖动任意边缘或四角可连续调整大小。
3. 点击卡片右上角的“查看 / 遮挡”可切换透明和不透明模式，也可以按 `Tab` 快速切换。
4. 按 `Esc`、点击关闭按钮或再次点击顶部“遮挡”即可关闭；切换论文时遮挡卡会自动收起。

透明模式会隐藏拖动提示、中央说明和快捷键文字，只留下极淡的模式与关闭图标；鼠标移到右上角后按钮会恢复清晰。遮挡卡只用于当前阅读界面，不修改论文，也不会随截图发送给 AI。

## 常见问题

### 为什么回答显示“需复核”？

回答使用了 AI 既有知识，或者部分结论缺少就近来源。该提示不代表回答一定错误，而是表示当前论文和网络来源无法完整验证它。

### 为什么问题会自动联网？

当问题包含“最近、最新、后续、优于、SOTA”等时效性表达，或询问的术语无法由论文片段解释时，网络检索 Agent 会自动启动。也可以在输入框上方手动开启“联网”。

### AI 为什么仍可能回答失败？

AI 服务可能出现网络错误、额度限制或空响应。程序会自动使用精简上下文重试；若重试仍失败，会显示接口警告和可用的论文原文，而不会静默空白。

### 如何暂停正在生成的回答？

AI 开始回答后，输入框右侧的发送图标会切换为方形暂停按钮。点击后会立即中断当前流式请求，保留已经生成的正文和来源，并在回答下方显示“生成已暂停”。输入框随后恢复，可以直接发送新的问题。
