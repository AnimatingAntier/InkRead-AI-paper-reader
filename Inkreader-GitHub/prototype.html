面向长上下文的高效稀疏注意力机制研究

林澈1,2 · 王叙白1 · 沈观澜2 · 顾青梧1 · 江晚舟2,†
1 澄怀智能研究院  ·  2 江南大学 人工智能与计算学院  ·  † 通讯作者

自注意力机制的二次复杂度长期制约着 Transformer 在长上下文场景中的应用。本文提出稀疏路由注意力（Sparse-Routed Attention, SRA）：一种受混合专家模型启发的注意力稀疏化范式，通过可学习的 Top-k 令牌路由器，将每个查询动态分配至最相关的键值块，在保持模型表达能力的同时将注意力计算量降低至近线性。在 128K 上下文长度的语言建模与检索基准上，SRA 以 3.1× 的推理加速取得了与全注意力相当的困惑度，并在「大海捞针」检索任务上超出稀疏基线 11.4 个百分点。

稀疏注意力长上下文Top-k 路由混合专家高效推理

01引言

近年来，大语言模型的上下文窗口从数千令牌扩展至数十万乃至百万量级，长文档理解、代码库级分析与多轮智能体交互等应用随之兴起。然而，标准自注意力机制[1]对序列长度的二次计算与显存开销，已成为制约长上下文模型落地的核心瓶颈。如何在几乎不损失模型质量的前提下降低注意力的渐近复杂度，是当前高效 Transformer 研究的主线之一。

既有工作大致沿两条路径展开：一类以固定稀疏模式近似全注意力，如局部滑动窗口与全局令牌相结合的 Longformer[3]；另一类则从系统层面优化精确注意力的 IO 开销，如 FlashAttention[4]。前者常因稀疏模式与内容无关而损失检索能力，后者虽高效却并未降低渐近复杂度。1本文观察到：注意力的稀疏结构本质上应当是内容依赖的——正如混合专家模型中路由器为每个令牌选择专家，查询亦应自主选择其最应关注的键值子集。

据此，我们提出稀疏路由注意力（SRA），其主要贡献包括：（i）一种可微分的 Top-k 键值块路由机制，使注意力稀疏模式随输入动态变化；（ii）面向路由训练稳定性的负载均衡正则；（iii）在 128K 上下文上的系统评测，验证了 SRA 在质量—效率权衡面上对既有稀疏基线的帕累托改进2。

02相关工作

高效注意力的研究可粗分为三类。固定模式稀疏化预设与内容无关的稀疏结构：稀疏 Transformer 采用分解的局部—跨步模式，Longformer[3]结合滑窗与任务驱动的全局令牌。低秩与核方法近似以线性复杂度逼近注意力矩阵，但在精确检索类任务上往往出现明显的能力回退。系统级优化中，FlashAttention[4]通过分块重算将精确注意力的显存占用降至线性，已成为训练的事实标准，但其计算量仍随序列二次增长。

与本文最接近的是基于聚类或哈希的内容感知稀疏注意力，以及混合专家模型中的条件计算思想[2]。SRA 的不同之处在于将路由单位从「单令牌对单专家」推广为「查询对键值块」，并引入块级负载均衡以适配注意力的因果掩码结构。

03方法：稀疏路由注意力

3.1 Top-k 令牌路由

给定查询序列 Q 与分块后的键值序列，SRA 首先以每个键值块的均值池化向量作为块摘要。路由器为轻量级线性层，计算查询 qi 对各块摘要的亲和度得分，并仅保留得分最高的 k 个块参与后续精确注意力计算。形式化地，查询 i 的注意力输出为：

oi = ∑j∈𝒯k(i) softmax( qikj⊤ / √d ) · vj,    𝒯k(i) = Top-kb ( Wr qi · sb )
(1)

其中 sb 为第 b 个键值块的摘要向量，Wr 为路由投影矩阵。直觉上，路由器扮演着「目录检索员」的角色：先翻阅各章节的摘要，再决定精读哪几章3，从而将每个查询的注意力开销从 O(L) 压缩至 O(k·B)，其中 B 为块大小。

3.2 路由正则与负载均衡

朴素 Top-k 路由易出现「赢者通吃」现象：少数块被过度路由，其余块因缺乏梯度而退化。受 Switch Transformer[2] 启发，我们引入块级负载均衡损失，鼓励路由分布在批维度上接近均匀；同时在路由 logits 上注入小幅探索噪声，缓解训练早期的路由坍缩。二者合计仅引入约 0.4% 的额外训练开销。

04实验

我们在 1.3B 参数规模、128K 训练上下文的主设置下评测 SRA，并与全注意力（FlashAttention-2 实现）、Longformer 及块状局部注意力基线对比。所有模型在相同数据与计算预算下训练。

05结论与局限

本文提出的稀疏路由注意力将混合专家模型的条件计算思想引入注意力稀疏化，在 128K 上下文上实现了质量与效率的帕累托改进。需要指出，当前评测限于 1.3B 规模与语言建模任务；SRA 在更大规模模型及多模态场景下的表现，以及路由器在分布外数据上的稳健性，仍有待验证。5代码与模型权重将于论文录用后开源。
